# 🐉 Dragon Dodge

Dragon Dodge is an endless survival platformer I'm building while learning web development.

## 🎮 About the Game

* Move left and right and jump across three floating platforms.
* Dodge fireballs launched by a dragon in the sky.
* Earn points for every fireball successfully dodged.
* Survive as the dragon's attacks become faster and more frequent.
* One fireball hit or falling off the platforms ends the run.

## 🛠️ Built With

* HTML
* CSS
* JavaScript

Currently in development. More features may be added as the game evolves!
